# 构建

设置变量，指定依赖库安装位置。

`XXXX_INSTALLED_DIR` 表示特定库安装的位置

OpenImageIO安装位置`OIIO_INSTALLED_DIR`

glm安装位置 `GLM_INSTALLED_DIR`

SDL2安装位置 `SDL2_INSTALLED_DIR`

部分库会使用`find_package`

如果没有找到，使用`XXXX_INSTALLED_DIR`链接。
